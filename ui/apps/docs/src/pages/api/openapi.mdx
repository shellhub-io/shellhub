# OpenAPI Specification

The REST API is described by an OpenAPI specification. [API Reference](/api/reference) renders it
in the browser; the files below are the same thing, to diff or to hand to a generator.

| Edition | Specification |
|---|---|
| **Community** | [community-openapi.yaml](/openapi/community-openapi.yaml) |
| **Cloud** | [cloud-openapi.yaml](/openapi/cloud-openapi.yaml) |
| **Enterprise** | [enterprise-openapi.yaml](/openapi/enterprise-openapi.yaml) |

**Take the one matching your edition.** Editions expose different routes: a Community server has
no MFA, firewall rule, or web endpoint routes at all, so a client generated from the wrong file
produces methods that answer 404. That is not a permission problem — the route is not there. See
[Editions](/about/editions).

Authentication is the `X-API-Key` header — see [API Authentication](/api).
