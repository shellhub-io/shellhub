# Introduction to ShellHub

ShellHub is an open source platform that gives you access to devices you cannot reach directly.
You install a small agent on a device, the agent dials out to the ShellHub server, and from then
on that device — and the things running on it — are available to you through a single address,
with every connection authorized against the identity of whoever is asking.

<Callout variant="info">
ShellHub is an **[open-source](https://github.com/shellhub-io/shellhub)** project and
can be self-hosted. See a comparison between the self-hosted and cloud-hosted versions
[here](/about/self-hosted-vs-cloud).
</Callout>

There is no inbound port to open and no public IP to arrange. The device makes the connection, so
it works from a customer's network, a factory floor, or a cellular link just as well as from a
rack you own. Once it is connected you can open a terminal, move files, forward a port, step into
a container, or publish an HTTP service it is running.

It takes a single command on the device to get there.
