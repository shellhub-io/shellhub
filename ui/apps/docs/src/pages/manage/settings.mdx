# Settings

Namespace settings apply to everything inside the namespace. They are split into sections:
**General** (name, tenant ID, leaving or deleting the namespace), **SSH** (the settings below),
**Provisioning keys** and, on Cloud, **Billing**.

<Shot id="namespace-settings" route="/settings/general" alt="Namespace Settings page" />

## Session recording

Whether the server records new sessions in this namespace. A new namespace starts with it on.

Community records the web terminal in the browser regardless — this setting is about the
**server-side** recording available on Cloud and Enterprise. See
[Sessions](/manage/sessions#recording).

## Connection announcement

A message shown in the terminal when somebody connects, labelled **Login banner** in the SSH
section and edited in a dialog from its **Edit** button.

Its most useful job is telling people recording is on. Somewhere between courtesy and a legal
requirement depending on where you operate, and it costs one sentence:

```
Sessions on this namespace are recorded.
```

It is also a reasonable place for an environment warning — anything that makes somebody pause
before typing on the wrong machine.

## SSH access mode

Chooses between the identity model and the legacy key-and-firewall model.

Namespaces created today are born in identity mode and **cannot leave it**. Namespaces that
predate identity mode default to legacy and can be switched across — and, while they are settling
in, switched back.

Switching to identity mode with no policies seeds the **Owner access** policy so default deny does
not lock the owner out. Everyone else starts with no access.

Do not switch without preparing. See
[Migrating from the Legacy Model](/manage/access-control/migrating-from-legacy).

## MFA requirements

On Cloud and Enterprise, whether members must have MFA enabled. See
[Multi-Factor Authentication](/manage/team/multi-factor-authentication).

## Instance-wide settings

Some things are not namespace settings but deployment configuration, set on the server rather
than here. See [Environment Variables](/selfhosted/environment-variables).
